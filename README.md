# پوشاک مانا — سایت کاتالوگ یک‌صفحه‌ای

یک سایت کاتالوگ کامل با **فقط HTML و CSS** (بدون جاوااسکریپت، بدون فریم‌ورک و بدون بیلد).
همه‌چیز در دو فایل است: `index.html` و `css/style.css` به‌همراه عکس‌ها در `assets/`.

## چه چیزهایی داخل سایت هست؟

- هدر چسبان + منوی موبایل (فقط با CSS)
- هیرو (بخش اول) با دو تصویر و آمار فروشگاه
- نوار مزیت‌ها (ارسال، ضمانت، تعویض، پشتیبانی)
- **گالری ۲۰ محصول** با فیلتر دسته‌بندی (فقط با CSS)
- **پنجره جزئیات هر محصول** (عکس بزرگ، جنس، سایزبندی، رنگ، دکمه سفارش در واتساپ)
- درباره فروشگاه + راهنمای خرید و جدول سایز (آکاردئون)
- نظر مشتریان
- **نقشه گوگل** + آدرس، تلفن، ساعت کاری و دکمه «مسیریابی»
- **دکمه شناور واتساپ** و نوار پایین صفحه در موبایل
- فونت فارسی «وزیرمتن» (از Google Fonts) و طراحی کاملاً راست‌به‌چپ

---

## ۱) اجرای سایت

ساده‌ترین راه: روی فایل `index.html` دوبار کلیک کنید.

برای اجرای درست‌تر (و تست روی گوشی در همان وای‌فای) در ترمینال داخل پوشه پروژه:

```bash
python -m http.server 8000
```

بعد آدرس `http://localhost:8000` را باز کنید. روی موبایل هم `http://IP-کامپیوتر:8000` را باز کنید.

## ۴) تغییر شماره واتساپ (مهم‌ترین کار)

شماره‌های واتساپ در لینک‌هایی مثل این هستند:

```html
https://wa.me/989121234567?text=...
```

- `989121234567` شماره واتساپ است **بدون ۰** و **با پیش‌شماره کشور** (ایران = ۹۸).
- مثال: `۰۹۱۲۱۲۳۴۵۶۷` → `989121234567`

در `index.html` با `Ctrl+H` (جایگزینی) همه‌ی `989121234567` را با شماره خودتان عوض کنید.
بخش `?text=` پیام آماده است؛ به آن دست نزنید تا پیام‌ها سالم بمانند.
شماره‌ی نمایشی (۰۹۱۲ ۱۲۳ ۴۵۶۷ و ۰۲۱-۸۸۷۷۶۶۵۵) را هم جداگانه با شماره واقعی جایگزین کنید.

## ۵) افزودن محصول جدید (گام‌به‌گام)

هر محصول دو بخش دارد: **کارت** در گالری و **پنجره جزئیات** در انتهای فایل.

### گام ۱ — عکس را اضافه کنید
عکس را با نام انگلیسی (مثلاً `coat-beige.jpg`) داخل `assets/images/products/` بگذارید.
بهترین اندازه: **۹۰۰ × ۱۲۰۰ پیکسل** (نسبت ۳:۴)، فرمت JPG، حجم زیر ۲۰۰ کیلوبایت.

### گام ۲ — کارت محصول
در بخش «کارت ۲۰» (آخرین کارت داخل `<div class="grid">`) این بلوک را کپی و بعد از آن بچسبانید.
شناسه‌ها باید یکتا باشند (`p-21`، `t-21`):

```html
<!-- ---------- کارت ۲۱ ---------- -->
<article class="card c-outer">
  <a class="card-media" href="#p-21" aria-label="مشاهده پالتو کرم">
    <span class="badge badge-new">جدید</span>
    <img src="assets/images/products/coat-beige.jpg" alt="پالتو کرم" width="900" height="1200" loading="lazy" />
    <span class="card-cta">مشاهده جزئیات</span>
  </a>
  <div class="card-body">
    <span class="card-cat">کت و کاپشن</span>
    <h3 class="card-title"><a href="#p-21">پالتو کرم</a></h3>
    <div class="card-price"><span class="price">۴٬۲۰۰٬۰۰۰ <small>تومان</small></span></div>
    <div class="swatches" aria-hidden="true"><i style="--c: #e9dfcd"></i><i style="--c: #2b2b2a"></i></div>
  </div>
</article>
```

کلاس دسته (`c-...`) تعیین می‌کند محصول در کدام فیلتر دیده شود:

| کلاس | دسته |
|---|---|
| `c-tee` | تی‌شرت و شومیز |
| `c-hoodie` | هودی و سویشرت |
| `c-outer` | کت و کاپشن |
| `c-pants` | شلوار |
| `c-dress` | مجلسی |
| `c-shoes` | کیف و کفش |
| `c-acc` | اکسسوری |

### گام ۳ — پنجره جزئیات
انتهای `index.html` (بعد از «محصول ۲۰») این بلوک را کپی کنید و متن/عکس/قیمت را عوض کنید.
**شناسه `id="p-21"` باید دقیقاً با `href="#p-21"` کارت یکی باشد** و `id` عنوان (`t-21`) یکتا باشد:

```html
<!-- محصول ۲۱ -->
<div class="modal" id="p-21" role="dialog" aria-modal="true" aria-labelledby="t-21">
  <a class="modal-shade" href="#products" aria-label="بستن پنجره"></a>
  <div class="modal-panel">
    <a class="modal-close" href="#products" aria-label="بستن">✕</a>
    <div class="modal-media">
      <img src="assets/images/products/coat-beige.jpg" alt="پالتو کرم" width="900" height="1200" loading="lazy" />
    </div>
    <div class="modal-body">
      <span class="card-cat">کت و کاپشن</span>
      <h3 id="t-21">پالتو کرم</h3>
      <div class="card-price"><span class="price">۴٬۲۰۰٬۰۰۰ <small>تومان</small></span></div>
      <p>پالتو پشمی با آستر گرم؛ مناسب روزهای سرد.</p>
      <dl class="specs">
        <div><dt>جنس</dt><dd>پشم و ویسکوز</dd></div>
        <div><dt>سایزبندی</dt><dd>M تا XL</dd></div>
        <div><dt>رنگ‌ها</dt><dd>کرم، مشکی</dd></div>
      </dl>
      <div class="sizes"><span>سایزهای موجود:</span><b>M</b><b>L</b><b>XL</b></div>
      <a class="btn btn-wa btn-block" href="https://wa.me/989121234567?text=%D8%B3%D9%84%D8%A7%D9%85%D8%8C%20%D8%B3%D9%81%D8%A7%D8%B1%D8%B4%20%D9%85%D8%AD%D8%B5%D9%88%D9%84%20p-21" target="_blank" rel="noopener">سفارش در واتساپ</a>
      <p class="modal-note">ارسال ۲۴ ساعته · پرداخت در محل</p>
    </div>
  </div>
</div>
```

> برای محصول جدید، در لینک واتساپ فقط `p-21` انتهای آدرس را با کد محصول عوض کنید.

### گام ۴ — شمارنده فیلتر
در بخش فیلترها (`.filters`) عدد کنار دسته‌ها را یک واحد زیاد کنید، مثلاً:
`<label class="chip" for="f-outer">کت و کاپشن <span class="count">۳</span></label>`
→ `۴`

### حذف محصول
کل بلوک `<article class="card ...">` و کل بلوک `<div class="modal" id="p-XX">` مربوط به آن را پاک کنید و شمارنده فیلتر را کم کنید.

## ۶) تغییر رنگ‌ها و ظاهر

بالای `css/style.css` بخش «متغیرها» را ببینید:

```css
:root {
  --paper: #f6f1e8;   /* رنگ پس‌زمینه سایت */
  --ink: #17140f;     /* رنگ متن و دکمه‌های تیره */
  --clay: #b4543a;    /* رنگ تأکید (تراکوتا) */
  --olive: #2f3d33;   /* سبز تیره (بخش نظرها) */
  --gold: #c79a4b;    /* طلایی (جزئیات و ستاره‌ها) */
  --radius: 20px;     /* گردی گوشه‌ها */
}
```

فقط کد رنگ‌ها را عوض کنید؛ بقیه سایت خودکار هماهنگ می‌شود.
برای تغییر فونت، لینک Google Fonts در `<head>` و مقدار `--font` در CSS را عوض کنید.

## ۷) ثبت فروشگاه در گوگل‌مپ + قرار دادن نقشه واقعی

### الف) ثبت کسب‌وکار در گوگل (Google Business Profile)
۱. به `https://business.google.com` بروید و با حساب گوگل وارد شوید.
۲. «افزودن کسب‌وکار» را بزنید و نام فروشگاه را وارد کنید.
۳. دسته‌بندی را انتخاب کنید (مثلاً «فروشگاه پوشاک»).
۴. آدرس دقیق و موقعیت روی نقشه را ثبت کنید.
۵. شماره تماس، ساعت کاری و وب‌سایت را وارد کنید.
۶. برای تأیید مالکیت، گوگل معمولاً یک ویدیوی کوتاه از مغازه یا کارت پستی می‌خواهد؛ مراحل را انجام دهید.
۷. بعد از تأیید، عکس، لوگو و توضیحات را کامل کنید تا در جست‌وجوی «پوشاک + نام محله» دیده شوید.

### ب) گرفتن نقشه برای سایت
۱. در گوگل‌مپ محل فروشگاه را پیدا کنید و روی **به‌اشتراک‌گذاری → درج نقشه** بزنید.
۲. کد `<iframe>` را کپی کنید.
۳. در `index.html` بخش `#contact`، آدرس داخل `src="..."` را با کد جدید عوض کنید.

روش ساده‌تر (بدون کد iframe): مختصات فروشگاه را در آدرس زیر بگذارید و نتیجه را در `src` قرار دهید:

```
https://maps.google.com/maps?q=35.7370,51.4100&hl=fa&z=16&output=embed
```

مختصات فعلی (`35.7370,51.4100`) یک نقطه نمونه در ولیعصر تهران است؛ آن را با مختصات واقعی عوض کنید.
همین مختصات را در دکمه «مسیریابی» هم به‌روزرسانی کنید:

```html
https://www.google.com/maps/dir/?api=1&destination=35.7370,51.4100
```

> نکته: در ایران باز شدن نقشه گوگل گاهی به تغییر DNS یا فیلترشکن نیاز دارد. اگر برای مشتری‌ها مشکل بود،
> می‌توانید به‌جای iframe یک تصویر از نقشه یا لینک به «نشان» و «بلد» بگذارید — بخش نقشه را حذف نکنید،
> فقط `src` را عوض کنید.

## ۸) انتشار سایت

سه گزینه ساده، بدون سرور و دیتابیس:

**۱. Netlify Drop (سریع‌ترین):** به `https://app.netlify.com/drop` بروید و کل پوشه پروژه را داخل صفحه بکشید؛
یک لینک آماده می‌گیرید و بعد می‌توانید دامنه (`manawear.ir`) وصل کنید.

**۲. GitHub Pages (رایگان):** فایل‌ها را در یک مخزن GitHub بگذارید → `Settings → Pages` →
شاخه `main` و پوشه `/ (root)` را انتخاب کنید.

**۳. هاست معمولی (cPanel):** فایل‌ها را داخل `public_html` آپلود کنید.

در هر سه حالت، فایل `index.html` باید در ریشه باشد تا صفحه اصلی سایت باز شود.

## ۱۰) نکات فنی (برای برنامه‌نویس)

- بدون جاوااسکریپت: فیلتر دسته‌ها با `input[type=radio]:checked ~ .grid`، منوی موبایل با `:target`،
  و پنجره محصول با `:target` کار می‌کند.
- تصاویر با `width`/`height` و `loading="lazy"` برای جلوگیری از پرش چیدمان.
- پشتیبانی از `prefers-reduced-motion` و فوکوس کیبورد (`:focus-visible`).
- نقطه‌های شکست: ۱۰۲۴ / ۹۰۰ / ۷۲۰ / ۶۴۰ پیکسل.
- برای دیدن سایت بدون اینترنت، فونت از Google Fonts بارگذاری نمی‌شود و به Tahoma برمی‌گردد؛
  اگر فونت آفلاین می‌خواهید، فایل `woff2` وزیرمتن را در `assets/fonts/` بگذارید و با `@font-face` معرفی کنید.
